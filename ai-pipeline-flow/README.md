# AI 客戶開發流水線（七張卡 → 合成流水線）

單檔 HTML，零依賴、離線可用、雙擊即開。1920×1080 舞台，任何窗口比例自動縮放置中。

## 流程（一頁過，共 8 下）

1. 一開：七張步驟卡淡淡鋪滿畫面（浮動）
2. 撳一下 → 亮一張（圓環描邊＋圖示＋大字），**突・突** 兩聲
3. 七張亮完，再撳一下 → 七張卡飛去中間，**串成一條流水線**
4. 出大字：**「唔使逐個做，串成一條流水線」**

## 操作

| 掣 | 作用 |
| --- | --- |
| 撳畫面 / 空白 / → | 出下一步；第七步後 → 合成 |
| `←` / `Backspace` | 退回一步 / 拆返散 |
| `End` / `Home` | 直接合成 / 重頭開始 |
| `R` | 重播合成 |
| `M` | 開 / 關音效 |
| `F` | 全螢幕（錄影用） |
| `H` | 收埋右下角 |

## 設計細節

- 字型：內嵌 Noto Sans TC 900（真粗黑體，子集約 16KB，唔靠系統合成粗體）
- 連線：只喺圓與圓之間出現、對準圓心，圓有實色底所以唔會劃過 icon
- 音效：瀏覽器 WebAudio 即時合成，冇外部檔案
- 改內容：`STEPS` 陣列（label / icon / color / x / y）
