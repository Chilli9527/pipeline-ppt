# 每日內容流水線 · 八步（森林綠版）

用「流水線PPT」個 setting（八張卡浮動 → 撳一下亮一張 → 串成一條流水線），換一套未用過嘅色。

## 色系

森林綠 ＋ 黃銅（同之前紅／藍兩款唔同）
底 #070C09 ｜ 強調 #C99A2E
卡色 #1FA97A #4CC38A #A3C74A #C99A2E #D97757 #2FBFAE #8FBF7F #B8865B

## 八步

1 熱話＋選題｜2 母稿｜3 配音｜4 出圖｜5 出動畫｜6 配樂＋字幕｜7 拆版本｜8 審批排程

收尾句：八步，串成一條流水線——**你每日只做三件事：揀題目、批一次、回覆留言**

## 操作

撳畫面／空白／→ 出下一步；第八步後再撳一下 → 合成。`←` 退回、`R` 重播、`M` 靜音、`F` 全螢幕、`H` 收右下角。

字型：內嵌 Noto Sans TC 900（真粗黑體，子集 14KB）。
