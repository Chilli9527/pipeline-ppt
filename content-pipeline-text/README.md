收尾：**八步，串成一條流水線**｜你每日只做三件：揀題目、批一次、回覆留言

## 操作

- 撳畫面 / 空白 / → ：出下一步（有突突聲），第八步後再撳 → 串成一條流水線
- ← / Backspace：退回｜End：直接串連｜Home：重頭
- R 重播串連｜M 靜音｜F 全螢幕｜H 收右下角｜? 操作表
- **冇自動播放、冇倒數**，邊錄音邊控節奏

## 技術

- 字型：Noto Sans TC 900 子集（14.3 KB）base64 嵌入，真粗黑，唔用系統假粗
- 音效：WebAudio 即時合成「突突聲」，冇外部檔
- 縮放：translate + scale，visualViewport / resize / ResizeObserver 三重保險
- 連線：線 z-index 1、圓 z-index 2 實色底，只喺圓與圓之間見到，唔會穿 icon
