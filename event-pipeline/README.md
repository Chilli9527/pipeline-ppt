# 活動流水線 · 十步（米白＋墨黑）

單檔 HTML，零依賴，雙擊即開。1920×1080 舞台，任何窗口比例都完整顯示。
**亮底設計** —— 之前五套都係暗底，呢套係新效果。

## 十步（4-3-3 排法）

| # | 步驟 | 色 | 講咩 |
|---|---|---|---|
| 1 | 開活動 | #8C2F39 | 定日子、名額、價錢 |
| 2 | 出報名頁 | #9E4038 | 自己工具生成，唔使買平台、唔使嵌 Form |
| 3 | 寫文案 | #B4552F | 一個活動出廣告文、Email 文、帖文 |
| 4 | FB 廣告 | #C0842C | 受眾、預算，草稿等批 |
| 5 | Email 群發 | #B39B2E | 一次發成個名單 |
| 6 | 群組通知 | #8C9440 | 同一篇發去群組 |
| 7 | 確認信 | #5E8452 | 報名即寄，附日曆 |
| 8 | 加日曆 | #33736B | 一撳入自己日曆 |

| 10 | 存檔覆盤 | #2B3A4A | 名單、出席、回覆留底 |

開場：小標 **活動報名 · 一條流水線** ＋ 大字 **開一個活動，唔使開十個工具**
收尾：**十樣嘢，一條流水線搞定**｜你唔係要多一個工具，你係要少十次手動

## 操作

- 撳畫面 / 空白 / → ：亮一張（突突聲），十張亮完再撳 → 串成一條流水線
- ← / Backspace：退回｜End：直接串連｜Home：重頭（會出返開場大字）
- R 重播｜M 靜音｜F 全螢幕｜H 收右下角｜? 操作表
- **冇自動播放、冇倒數**

## 亮底特別處理（同暗底版唔同）

- 卡唔用透明度做「未亮」，改用底色 #EDE8DE → 白紙 + 陰影，喺米白底先睇得清
- 圓底改白、文字改墨黑、光斑降到 5%
- 連線仍然係 z-index 1、圓 z-index 2 實色底，只喺圓與圓之間見到

## 技術

- 字型：Noto Sans TC 900 子集 15.5 KB base64 嵌入（真粗黑）
- 音效：WebAudio 即時合成「突突聲」
- 縮放：translate + scale，visualViewport / resize / ResizeObserver 三重保險
