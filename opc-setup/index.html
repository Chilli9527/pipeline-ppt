0a. 兩段照抄：第一段你自己做，第二段貼給阿強

次序唔可以亂：先開帳號 → WorkBuddy → Zo → DSH → DS Bot → 員工 → 之後才有阿強接手。

第一段：你自己做（未有 Bot，跟住做就得）

STEP 1  註冊帳號（先開齊，唔使等）
□ DeepSeek        https://platform.deepseek.com
□ Zo Computer     https://zo.computer
□ WorkBuddy       https://workbuddy.ai
□ Upload-Post     https://upload-post.com
□ Brevo           https://brevo.com

□ Google Cloud    https://console.cloud.google.com （YouTube 上載才要）
※ 每個都係你自己開、自己嘅帳號，唔關我事

STEP 2  裝 WorkBuddy（剪片廠）
① workbuddy.ai 下載 → 裝 → 登入
② Mac 另裝 Palmier Pro → https://github.com/palmier-io/palmier-pro/releases
   Windows 剪片用 ChatCut → https://www.chatcut.io/download
③ 開住 WorkBuddy（剪片時 Palmier 要開住）
Mac 開唔到：系統設定 → 私隱與安全性 → Open Anyway

STEP 3  裝 Zo Computer（7×24 工廠）
① 瀏覽器開 https://zo.computer → 登入
② Settings → API → 產 Access Token（留住，第 5 步要用）
③ 喺 Zo 網頁逐個撳 Connect：Google（Gmail／Calendar／YouTube）、Notion、Telegram
（Zo 唔使裝 app，用瀏覽器）

STEP 4  裝 DeepSeek Harness（DSH）
← 我發你安裝檔（官網冇公開下載頁）
裝完開 app → 設定 → 模型 → 填 DeepSeek API key

STEP 5  裝 DS Bot（Bot 介面）—— 只有桌面版
https://github.com/Fei2411/DS-Bot/releases/latest
→ 下載安裝 → 第一次開用預設資料夾
Mac 開唔到：系統設定 → 私隱與安全性 → Open Anyway
Windows 警告：More info → Run anyway
→ 見到 Bot 介面（左邊 Bot 列表，未裝員工前係空）

STEP 6  裝員工檔案（17 個 Bot，包括阿強）
① 解壓 AI-Lion-OPC-Template.zip
② 雙擊 chooser.html → 剔要邊幾個 → 撳「下載 config.json」
③ config.json 放返模板資料夾
④ 完全退出 DS Bot（Mac Cmd+Q；Windows 系統匣 → Quit）
⑤ 雙擊 Install.command（Windows：Install.bat）
⑥ 重開 → 左邊見到 17 個 Bot，第一個就係阿強·CEO

STEP 7  接 WorkBuddy（貼提示詞落 WorkBuddy，唔使自己改檔）
開 WorkBuddy → 新對話 → 貼下面（換成你自己兩個 key）：

幫我加兩個 MCP server 落 ~/.workbuddy-ai/mcp.json，唔准刪任何現有 server：
1. upload-post：type http；url https://mcp.upload-post.com/mcp
   headers: Authorization: ApiKey 【你嘅 Upload-Post key】
2. fal-ai：type http；url https://mcp.fal.ai/mcp
   headers: Authorization: Key 【你嘅 fal key：ID:SECRET】
改之前先備份做 mcp.json.bak-今日日期；寫完驗 JSON 讀得返；
最後報我總共有幾個 server，同呢兩個 server 叫咩名。
我嘅兩個 key 下一句貼，你寫入後唔好再顯示返出嚟。

→ 佢答「已寫入，共 N 個 server」＝接通，然後完全退出 WorkBuddy 再開

第 5 步：裝 DS Bot（桌面版 —— 只有呢一個方法）

  1. 開 https://github.com/Fei2411/DS-Bot/releases/latest → 下載你系統嘅安裝檔（Mac .dmg／Windows .exe）

  3. 系統警告「未簽署」：Mac → 系統設定 → 私隱與安全性 → Open Anyway；Windows → More info → Run anyway

桌面版自帶 DSH，資料獨立（~/.ds-bot vs ~/.dsh），唔會打架。

  1. 解壓 AI-Lion-OPC-Template.zip（我發你）

模板有 17 個 Bot；我而家 19 個（多咗 2 個係我後來自己加，你可以後加）。

D · 介面（DS Bot）到底要唔要另外裝？

唔使。 DSH 一開就係 DS Bot 介面：左邊 Bot 列表、中間對話、任務卡、群聊。

  • 學生版：就咁用內建介面，唔使裝任何嘢
  • 想多一個「睇數」儀表板分頁（我部機有）：裝 dsh-dashboard-tab 插件，屬可選
  • 如果你見到側欄冇 Bot 列表，通常係未登入／未開 Bot，唔係介面壞

6. 十個一定會撞到嘅錯

（全部係我自己撞過、有實例嘅，唔係理論）

  • Upload-Post 有 key 但冇 Connect 平台：最易中。key 只係身份，平台要逐個撳 Connect／授權。發唔出就先去後台睇每個平台有冇「已連接」。
  • Brevo 未驗寄件網域：寄件人網域要加 SPF／DKIM。唔驗證：大批 bounce、入 spam，名單會壞。
  • YouTube 授權揀錯頻道：一個 Google 帳號可以有幾個頻道（AI Lion／AI Bunny）。授權畫面要揀對，上載後一定開連結核實。
  • YouTube API 配額用盡：每日 10,000 單位，上載一條約 1,600 → 一日最多 6 條。爆咗改用 Upload-Post。
  • fal.ai 冇 credit：出圖回 402。先入 Dashboard 睇餘額，唔好以為 skill 壞。
  • ZO_TOKEN 過期：Zo 全部工具 401。重新產 token，更新 DSH 密鑰，重開 DSH。
  • Palmier 冇開：palmier MCP 連唔到 127.0.0.1:19789。開住 app 再叫 Bot 做。
  • WhatsApp 發送號唔在群：會回 you're not participating in that group。群發前先確認號碼喺群裡面；失敗群要照實記錄，唔可以當成功。
  • 圖片太大，上載 timeout：9.6MB 圖發 WhatsApp 群，45 秒 timeout，成功率先跌。統一轉 1080px JPEG（約 0.9MB）就穩。
