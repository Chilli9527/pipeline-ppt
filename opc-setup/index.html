1. 安裝：5 步（3 步叫 Bot 做，2 步你自己做）

你唔需要識命令、唔需要開終端機。 下面每步寫明「你講咩」同「Bot 做咩」。

步你做對 Bot 講（照抄）Bot 會做咩
1裝 app：DSH、WorkBuddy、Chrome（Mac 另加 Palmier，Windows 加 ChatCut）——
2雙擊解壓 AI-Lion-OPC-Setup.zip，出一個資料夾——
3右鍵資料夾「複製路徑」，貼落對話框「裝晒呢個資料夾入面所有 skill，做完報我數」逐個複製去 ~/.dsh/skills 同 ~/.workbuddy-ai/skills，跳過已存在嘅，最後驗一次有冇缺 SKILL.md
4打開 mcp-block.json，貼兩個 key（upload-post、fal-ai）存檔「mcp-block.json 我填好兩個 key，幫我跑 merge-mcp.py」把呢兩個 server 併入 WorkBuddy 嘅 mcp.json，改之前自動備份，唔會刪你其他 server
5DSH → 密鑰，逐個貼（見下表）可叫 Bot：「列出我未填嘅密鑰」提醒你邊個未填；值只有你自己貼得，Bot 見唔到明文

驗收：一定要見到呢兩個數字

  • 裝 skill 後：DSH 11 個 ／ WorkBuddy 38 個 ＝ 49 個
  • 接 MCP 後：Bot 報「已寫入，現時共 N 個 server」，並提你重開 WorkBuddy
  • 兩個步驟做完都要重開 app 一次，新嘢才會被讀到

補：想自己動手（唔建議，但得）

真係想自己開終端機就跑呢兩句 —— 同叫 Bot 做完全一樣：

chmod +x install-skills.sh && ./install-skills.sh
python3 merge-mcp.py --check && python3 merge-mcp.py

--dry-run 只印會做咩、唔改檔；--force 覆蓋舊版（會先備份）。

2b. 註冊完仲要做（呢欄最易漏）

好多人以為「拿到 key = 裝好」。其實 key 只係身份，帳號仲要逐個接。 打圈嗰三個最多人漏：

服務註冊完仲要做做漏會點
② Upload-Post去後台逐個平台撳 Connect／授權：YouTube 頻道、Facebook 專頁、Instagram、Threads、LinkedIn、X有 key 但冇接平台 → 發唔出，回錯誤，你會以為 skill 壞

Google CloudOAuth 授權畫面要揀對頻道（AI Lion／AI Bunny 係兩個唔同頻道）上載去錯頻道，或者上載完見唔到片
Notion喺目標 page 右上「⋯ → Connections」加返個 integrationBot 讀唔到你個 page，話 404
Telegram你自己喺 Telegram 撳一下 /startBot 發唔到訊息給你（未知收件人）

6. 十個一定會撞到嘅錯

（全部係我自己撞過、有實例嘅，唔係理論）

  • Upload-Post 有 key 但冇 Connect 平台：最易中。key 只係身份，平台要逐個撳 Connect／授權。發唔出就先去後台睇每個平台有冇「已連接」。
  • Brevo 未驗寄件網域：寄件人網域要加 SPF／DKIM。唔驗證：大批 bounce、入 spam，名單會壞。
  • YouTube 授權揀錯頻道：一個 Google 帳號可以有幾個頻道（AI Lion／AI Bunny）。授權畫面要揀對，上載後一定開連結核實。
  • YouTube API 配額用盡：每日 10,000 單位，上載一條約 1,600 → 一日最多 6 條。爆咗改用 Upload-Post。
  • fal.ai 冇 credit：出圖回 402。先入 Dashboard 睇餘額，唔好以為 skill 壞。
  • ZO_TOKEN 過期：Zo 全部工具 401。重新產 token，更新 DSH 密鑰，重開 DSH。
  • Palmier 冇開：palmier MCP 連唔到 127.0.0.1:19789。開住 app 再叫 Bot 做。
  • WhatsApp 發送號唔在群：會回 you're not participating in that group。群發前先確認號碼喺群裡面；失敗群要照實記錄，唔可以當成功。
  • 圖片太大，上載 timeout：9.6MB 圖發 WhatsApp 群，45 秒 timeout，成功率先跌。統一轉 1080px JPEG（約 0.9MB）就穩。
