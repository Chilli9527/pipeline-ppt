6. 十個一定會撞到嘅錯

（全部係我自己撞過、有實例嘅，唔係理論）

  • Upload-Post 有 key 但冇 Connect 平台：最易中。key 只係身份，平台要逐個撳 Connect／授權。發唔出就先去後台睇每個平台有冇「已連接」。
  • Brevo 未驗寄件網域：寄件人網域要加 SPF／DKIM。唔驗證：大批 bounce、入 spam，名單會壞。
  • YouTube 授權揀錯頻道：一個 Google 帳號可以有幾個頻道（AI Lion／AI Bunny）。授權畫面要揀對，上載後一定開連結核實。
  • YouTube API 配額用盡：每日 10,000 單位，上載一條約 1,600 → 一日最多 6 條。爆咗改用 Upload-Post。
  • fal.ai 冇 credit：出圖回 402。先入 Dashboard 睇餘額，唔好以為 skill 壞。
  • ZO_TOKEN 過期：Zo 全部工具 401。重新產 token，更新 DSH 密鑰，重開 DSH。
  • Palmier 冇開：palmier MCP 連唔到 127.0.0.1:19789。開住 app 再叫 Bot 做。
  • WhatsApp 發送號唔在群：會回 you're not participating in that group。群發前先確認號碼喺群裡面；失敗群要照實記錄，唔可以當成功。
  • 圖片太大，上載 timeout：9.6MB 圖發 WhatsApp 群，45 秒 timeout，成功率先跌。統一轉 1080px JPEG（約 0.9MB）就穩。
