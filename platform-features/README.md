## 操作

- 撳畫面 / 空白 / → ：亮一張（突突聲），12 張亮完再撳 → 串成一條流水線
- ← / Backspace：退回｜End：直接串連｜Home：重頭
- R 重播｜M 靜音｜F 全螢幕｜H 收右下角｜? 操作表
- **冇自動播放、冇倒數**

## 技術

- 12 張卡 4×3（330×210）；合成後 12 個迷你節點（96px 圓，150px 間距）
- 字型：Noto Sans TC 900 子集 17.5 KB base64 嵌入（真粗黑）
- 音效：WebAudio 即時合成「突突聲」，冇外部檔
- 縮放：translate + scale，visualViewport / resize / ResizeObserver 三重保險
- 連線：線 z-index 1、圓 z-index 2 實色底，只喺圓與圓之間見到
