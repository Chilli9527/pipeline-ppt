# 口播 Video 流水線 · 八步（藍色版）

同 `youtube-pipeline-flow` 一模一樣嘅結構同互動，只換色系。

## 同紅色版嘅分別

| | 紅色版 | 藍色版（呢個） |
| --- | --- | --- |
| 底色 | #08070A（暖黑） | #05070E（冷藍黑） |
| 八步色 | 紅橙黃青藍 | 藍／天藍／青／薄荷／檸檬／紫／粉紅 |
| 強調色 | #FF5470 粉紅 | #46C8FF 冰藍 |
| 長條 | 紅橙漸變 | 藍青漸變 |
| YouTube Logo | 一樣 | 一樣（品牌紅唔改） |

## 操作

撳畫面／空白／→ 出下一步；第八步後再撳一下 → 串成一條流水線。
`←` 退回、`R` 重播合成、`M` 靜音、`F` 全螢幕、`H` 收右下角。

八步：定題 → 寫稿 → 配音 → 出圖 → 出動畫 → 配樂＋字幕 → 剪接 → 上載
