# 做一條口播 Video，上載去 YouTube Channel（PPT 版）

單檔 HTML，零依賴、雙擊即開。1920×1080 舞台，任何窗口比例自動縮放置中。

## 9 頁（8 步 + 收尾）

1. 定題　2. 寫稿　3. 配音　4. 出圖　5. 配樂＋字幕　6. 剪接　7. 上載　8. 八步串成一條流水線

- 第 7 頁有 YouTube Logo（未公開 → 公開）
- 第 8 頁七個節點用同一個 logo 語言收尾
- 每頁一個顏色：紅 → 橙 → 黃 → 青 → 藍 → YouTube 紅

## 操作

| 掣 | 作用 |
| --- | --- |
| 撳畫面 / 空白 / → | 下一頁 |
| ← / Backspace | 上一頁 |
| Home / End | 第一頁 / 最後一頁 |
| F | 全螢幕 |
| H | 收埋左下角提示 |

## 字型

內嵌 Noto Sans TC 900（真粗黑體，子集約 15KB）。
改字後如果新增字元，要重新造子集。
