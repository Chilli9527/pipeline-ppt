# 口播 Video 流水線 · 八步（浮動卡版）

同 `ai-pipeline-flow` 一樣嘅玩法，但內容換成做 YouTube 片嘅八步，色系跟 YouTube。

## 流程（一頁過，共 8 下）

1. 七張卡淡淡鋪滿畫面（浮動）
2. 撳一下 → 亮一張（圓環描邊＋圖示＋大字），**突・突** 兩聲
3. 七張亮完，再撳一下 → 全部飛去中間，**串成一條流水線**
4. 出大字：「八步，串成一條流水線」

## 八步

定題 → 寫稿 → 配音 → 出圖 → 出動畫 → 配樂＋字幕 → 剪接 → 上載

## 操作

| 掣 | 作用 |
| --- | --- |
| 撳畫面 / 空白 / → | 出下一步；第八步後 → 合成 |
| `←` / `Backspace` | 退回 / 拆返散 |
| `End` / `Home` | 直接合成 / 重頭 |
| `R` | 重播合成 |
| `M` | 開 / 關音效 |
| `F` | 全螢幕（錄影用） |
| `H` | 收埋右下角 |

## 設計

- 色：紅／橙／黃／青／藍／YouTube 紅（逐張卡一個色）
- YouTube Logo：頂部標題同第八步「上載」用同一個 play 標記
- 字型：內嵌 Noto Sans TC 900（真粗黑體，子集 ~12KB）
- 連線：只喺圓與圓之間出現，對準圓心
